# 林益綺 Lin Yi-Chi — Personal Site

個人自我介紹網站：https://boringman1031.github.io/

- React 19 + Vite
- 動畫元件來自 [React Bits](https://reactbits.dev)（PixelBlast、DecryptedText、RotatingText、CountUp、ShinyText、SpotlightCard）
- 推送到 `main` 後由 GitHub Actions 自動部署到 GitHub Pages

## 開發

```bash
npm install
npm run dev
```

網站文字（中／英）都集中在 `src/data.js`，修改內容只需編輯該檔案。
